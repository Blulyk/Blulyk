## 👋 About me

I'm **Blulyk**, a Computer Engineering student at **UEMC (Universidad Europea Miguel de Cervantes)**.

I use GitHub as a **public engineering lab**: a place where I build, test, break, improve and publish software while learning how real systems work.

- 🎓 Studying **Computer Engineering**
- 🤖 Interested in **AI-powered applications and autonomous systems**
- ⚙️ Building **automation and practical software**
- 🐳 Running and experimenting with **Docker, NAS and self-hosted infrastructure**
- 📱 Developing across **Android, iOS and the web**
- 🧪 Turning ideas into working prototypes instead of leaving them as concepts
- 🎯 Long-term goal: become an excellent software engineer and work on ambitious technology
